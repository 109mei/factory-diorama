# 6観点の段階レビュー

2026-10-02。対象はブラウザ内の工場ゲームです。実物の工場設備・材料強度・製造安全性を検証するものではありません。以下は6人の実在する専門家の合意を装うものではなく、役割を分けた実装側と独立レビュー側の確認記録です。

## 要求・構想

機械の構造と質感を詳しくし、素材の変化・搬送・作動を見る楽しさを増やす。工程とコイン収入を段階的に拡張する。工場上の名前ラベルを外し、設備選択・増設で滑らかに近づく。既存データを失わず、縦画面で操作できることを基準にしました。

有限の7工程、各設備6基。未開放の加工は搬送路で迂回し、初期状態から出荷できます。各素材が自分の加工度・価値を持ち、開放時に既存の荷物を勝手に値上げしません。

## 役割と確認基準

1. 設計：要求との対応、7工程の接続、機械の機能と形の対応、開放による実際の増加。
2. 実装・製造性：ソフトウェア実装として材質・形状・再利用・費用・描画負荷を確認。外部有料素材なし、静的結合・インスタンス化・上限付き管理。
3. 品質・安全：不正保存、連打、非表示復帰、未保存データ、WebGL停止、ロック設備、在庫消失を検査。
4. 解析：独立した収支計算、素材保存則、時間刻み、移行、乱数シナリオ、カメラの30/60/120Hz比較。
5. 利用者・保守：320px操作、名前のない画面での導線、全景へ戻る操作、視差低減、セーフエリア、大きな残高、破損からの復帰。
6. 統合：機械・素材・価格・UI・保存の整合、修正後の回帰、ビルドと公開後の確認。

## 再レビュー・統合

独立した経済・移行・状態・描画グラフ検査と、別の設計/利用者観点の検査を実施。実装側は機械構造・材質・ランタイム所有権・破棄処理を確認しました。全体テスト結果と制限は [qa.md](qa.md) に記載しています。

未完了の確認は、WebGL対応環境での実描画品質と実機操作です。実画像が得られない部分を、模型画像や合成映像で確認済みにしていません。音声の新要望は別変更で実装し、音量・イベント頻度・ライフサイクルを確認しています。主観的な音の心地よさは、実際に聴くまで評価済みとしません。


## 音声追加の6観点

1. 設計：工場を眺める体験を邪魔しない低い機械音と素材の音。外部音源なし、初期オフ。
2. 実装：長いノイズバッファを再利用し、同時発音を上限4に制限。音声設定を生産セーブと分離。
3. 品質：操作前の自動再生を防止。非表示・描画停止・デバイス中断・無効化競合・破棄を検査。
4. 解析：振幅予算、リミッター曲線、包絡、イベント頻度、離席後の大量再生の抑制を検査。
5. 利用者：♪の切替、音量スライダー、待機/利用不可表示、設定保持。実際に聴いた評価とは区別。
6. 統合：実シミュレーションの加工/出荷を受け取り、表示と音声のライフサイクルを接続。保存・終了を含む統合テストを追加。

公開前の独立した音声/統合レビューと、公開後のDOM確認を別の確認段階とします。現在までの検査に、実機の音質評価や安全な音圧の保証は含めていません。


### 音声の追加指摘と修正

- iOSでは早いpointerdownだけでは開始条件を満たさない場合があるため、タッチ終了/クリック系へ変更し、開始成功まで入口を保持。
- 保留したresume()が次の有効な操作を妨げる問題を、操作ごとの再試行と古い試行の無効化で修正。
- 開始中/再生中/失敗を分け、保留が2.5秒続く場合は再試行を案内。単なる「オン設定」を実再生として表示しない。
- 6つのランタイム回帰で、再試行・タイムアウト・古い結果・無効化・非表示・破棄を検査。音の聞こえ方の確認は依然として未完了。


## 断面・搬送・長押しカメラの追加レビュー

要求→構想→重要接続→部品→修正→再検査→統合の順に、同じ6観点を適用しました。

1. 設計：内部の働きを観察できる開放断面。加工中の素材変化と待機列を分離し、カメラを動かしても視点方向を保つ。
2. 実装：既存材質/静的結合を再利用。貨物IDに対応する7番目の溶融形状と開いた箱のインスタンスだけを追加。外部素材やサービスなし。
3. 品質：明示的ミュートの保持、旧OFFの不確実性を勝手に解釈しない。複数指や中断後に意図しないカメラ移動を残さない。
4. 解析：搬送時間を2倍にしても定常能力と資産を維持。保存移行、収支、各加工フェーズ、形状底面/上面、実際の交差判定を確認。
5. 利用者：最初の通常操作から音を開始。長押し後は追加待ちなしの連続移動、短いタップで設備選択、全景への復帰、説明文を更新。
6. 統合：固定した候補に対する独立再検査、全体テスト、型検査、本番ビルド、公開後のDOM確認を段階分けする。
