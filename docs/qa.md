# 検証記録

## 2026-10-02 ローカル候補版

- 環境: 自動検証用Linux環境、Node.js 24.19.0、Vite 7.3.6、Three.js 0.180、Vitest 3.2.7。
- 自動テスト: 35件。生産の完遂、素材保存則、最初の60秒での購入機会、連続購入、資金不足、最大レベル、固定刻み一致、30分動作、保存復帰、不正データ、未知バージョン、時刻巻き戻り、30分上限、日本語UI状態、ヘルプ開閉、非表示/復帰の二重生産防止、遅延pagehideの保存時刻。
- TypeScript型検査: 成功。
- Vite本番ビルド: 成功。相対アセットパスを使用。
- テストは実装前に失敗を確認してから実装。追加のライフサイクル3件も未実装で失敗→実装後成功を確認。

## 独立レビューと修正

- 最初の20 C取得を29.6秒で独立に確認。
- 80個の再現可能な30分シナリオで、素材保存則、購入額と資金の一致、ID一意性、工程ごと18個・全体108個の上限を確認。
- 上位採掘機の端数時間の消失、短い横画面での最低高さ、滞留した搬送品の重なりを修正。回帰テストは修正前に失敗し、修正後に成功。
- 描画器を代替したシーングラフ検査では、初期36メッシュ/21ジオメトリ、最大48メッシュ/33ジオメトリ。120回の更新後も安定。これは実機の描画速度計測ではありません。
- 390×844と320×568に相当する投影計算では、静的形状がカメラ範囲内に収まることを確認。これは実画像による確認の代わりにはなりません。
- シーン破棄時の材質解放も修正。実際のシーングラフを用いたテストで、16/21個だけが解放される失敗を再現し、煙と選択リングを含む21/21個すべての解放を確認。

## 公開URLでの実ブラウザ確認

2026-10-02、公開された実アプリの`qa.html`をChromeクラウドブラウザで操作しました。

- 390×844、320×568、844×390の実際のiframe表示を撮影。
- 320×568、844×390で主要操作が画面内に収まり、各タブ/ヘルプ/購入ボタンが44px以上の高さを持つことをDOM座標で確認。
- 製錬炉の選択、20 Cの購入（30→10 C、Lv.1→Lv.2）、資金不足ボタンの無効化、ヘルプ開閉、再読み込み後の設備レベルと資金の保存を実操作で確認。
- WebGL初期化失敗時のステータス文言と狭い画面のエラーカードを調整。変更後の再公開確認は次のチェック対象。

### 3D表示の確認は未完了

このテスト用ChromeはWebGLが無効です。実コンソールに`GL_VENDOR = Disabled, GL_RENDERER = Disabled`、`THREE.WebGLRenderer: Error creating WebGL context`を確認しました。アセットの読み込みやUIのJavaScriptは実行できましたが、3D描画を開始できませんでした。

スクリーンショットは実際のエラー画面とヘルプ画面です。工場の3D外観、搬送アニメーション、増設の見た目、GPU性能を検証した画像ではありません。WebGLが有効な別環境で3D表示・動作を確認する必要があります。実機iPhone/Safari、実タッチ、セーフエリア、実測FPSは未検証です。

## 表示チェック用ページ

`qa.html` は実際のゲームを同一オリジンのiframeに埋め込み、390×844、320×568、844×390の表示領域で操作できます。モック画像は使用しません。通常画面と保存データが共通なので、同時に複数のゲーム画面を開かず検証します。これは実機のタッチやSafari、セーフエリアの検証を代替しません。
