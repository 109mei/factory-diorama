# 鉱脈ライン / MINE LINE WORKS

小さな採掘場から、7工程の製造ラインへ。素材の姿と価値が変わり、機械と搬送が増えていく縦画面3Dファクトリーです。

## 遊び方

最初は採掘と出荷が動き、原石1個で2 Cを獲得します。資金を貯めて新しい工程を順に開放すると、その工程を実際に通った製品の価値が上がります。

| 工程 | 開放費用 | 加工後の出荷価値 |
|---|---:|---:|
| 採掘・出荷 | 最初から | 2 C |
| 破砕 | 40 C | 4 C |
| 選別 | 120 C | 7 C |
| 製錬 | 360 C | 12 C |
| 成形 | 900 C | 20 C |
| 梱包 | 2,200 C | 32 C |

- 下の設備一覧を左右にスクロールし、設備を選びます。カメラが同じ向きのまま近づきます。
- 上の目標を押すと、次に開放できる工程へ移動します。
- 増設すると並列の設備が増え、生産能力が上がります。荷物の滞留がある工程を優先しましょう。
- 「全景」で工場全体の表示に戻ります。工場上に設備名のラベルは表示しません。
- 全7工程、各設備は最大6基です。無限に新しい工程が増えるゲームではありません。
- 操作系と画面の確認用に [qa.html](./qa.html) を同梱しています。これは実アプリの表示領域を変えるページです。

## 保存と旧版からの引き継ぎ

このブラウザのlocalStorageに自動保存します。離席中の進行は最大30分です。

v1からの更新では、資金・購入済み設備・在庫・生産の進捗を保持します。旧版の製錬と成形に必要な前工程は開放済みとなり、梱包が次の拡張になります。すでに出荷待ちの旧製品は元の5 Cを保持し、新しい工程で実際に加工された時だけ価値が変わります。

新しい保存領域を使い、旧データはバックアップとして残します。新保存が破損した場合は有効な旧データからの復帰を試みます。ブラウザの保存データを消すと進行も消えます。複数のゲーム画面を同時に開く運用は避けてください。

## 開発

Node.js 22.12以上。

```sh
npm ci
npm run dev
npm test
npm run typecheck
npm run build
npm run preview
```

制限付き環境では `npm run dev -- --host 127.0.0.1` を使用できます。

- Three.js + TypeScript + Vite
- ルール計算は100ms固定刻みで描画と分離
- 原石・砕石・選鉱石・インゴット・歯車部品・製品箱の6形状
- 機械、配管、歯車、油圧ラム、ローラー、構造物、反射用テクスチャはコードによるオリジナル生成
- 材質単位の結合とInstancedMesh、描画物数の上限、解放処理を検証
- カメラと搬送の追従はフレーム時間に基づき、OSの視差効果を減らす設定に対応
- アカウント、広告、課金、外部モデルのダウンロードはありません
